# Site Associação SOMAR

Este projeto é um site institucional responsivo, criado a partir da referência visual fornecida.

## Arquivos
- index.html — estrutura e conteúdo do site
- style.css — identidade visual, layout e responsividade
- script.js — menu mobile, navegação ativa, formulário e ano automático

## Antes de publicar
Substitua os dados de exemplo por informações oficiais:
- telefone/WhatsApp
- e-mail
- endereço
- links das redes sociais
- textos e notícias
- imagens
- domínio

As imagens de demonstração usam URLs do Unsplash. Para produção, é recomendável baixar/substituir por imagens próprias ou devidamente licenciadas.

## Teste local
Abra `index.html` no navegador.

## Publicação
O site é estático e pode ser publicado em serviços de hospedagem de sites estáticos. Depois da publicação, o domínio do Registro.br pode ser apontado para a hospedagem seguindo os registros DNS fornecidos por ela.
